# План создания стартового проекта

Цель — подготовить проект для VS Code по актуальному краткому ТЗ v2. Это стартовая реализация с демонстрационными данными, а не принятая бухгалтерией система.

Архитектура: Python 3.11+, стандартная библиотека, CLI и XLSX. Нормализованные записи источников отделены от сравнения и экспорта. Один режим обращается только к предусмотренным ТЗ адаптерам. Реальные адаптеры закрыты до согласования контрактов; отсутствие данных не заменяется нулём. В первой поставке нет сетевых запросов и распознавания финансовых документов.

- [x] Написать и выполнить тесты допустимых периодов, точной арифметики, пропусков, дублей, неподтверждённых правил и изоляции источников.
- [x] Реализовать модели, проверки периода, сравнение и демонстрационные адаптеры.
- [x] Написать и выполнить проверки CLI и XLSX, включая отдельные месячные сравнения, сохранение истории и строки, похожие на формулы Excel.
- [x] Реализовать CLI и экспорт; неподготовленный реальный запуск завершается неполным результатом и ненулевым кодом.
- [x] Добавить настройки VS Code, инструкции запуска, реестр правил и исходные документы.
- [x] Выполнить полный набор тестов, проверить XLSX независимым читателем, запустить все режимы и открыть workspace в VS Code.

Особое внимание: отсутствие строки и нулевое значение; одинаковые итоги при отдельных расхождениях; разные разрезы; недопустимые даты; неполный источник; неподтверждённые правила. Знаки сравнений в демонстрации — левая сторона минус правая, для реальных данных знак должен быть утверждён.

Проверка 19 октября 2026 года: 19 unittest-тестов прошли. Три книги из examples независимо прочитаны openpyxl из среды проверки; структура листов, количество сравнений и отсутствие формул подтверждены. Настройки VS Code и реестр правил проверены JSON-парсером. Зависимость openpyxl нужна только внешней проверке и не требуется самому проекту.
